# 杭职大继续教育学院 - 电脑端管理后台

## 快速启动（3步搞定）

### 第1步：安装 Node.js（如果没装过）
1. 打开 https://nodejs.org/
2. 下载 **LTS（长期支持版）** 并安装
3. 安装时一路点"下一步"即可

### 第2步：获取云开发密钥
1. 打开 https://mp.weixin.qq.com/ 并登录
2. 点击左侧 **「开发」** → **「开发管理」**
3. 点击 **「开发设置」** 标签
4. 找到 **「云开发」** 部分，点击 **「前往查看」**
5. 在云开发控制台，点击左上角 **「设置」** → **「环境设置」**
6. 复制 **SecretId** 和 **SecretKey**
7. 打开 `admin-server/config.json`，把 SecretId 和 SecretKey 填进去

### 第3步：启动管理后台
1. 双击 `admin-server\启动管理后台.bat`
2. 等待自动安装依赖（第一次需要几分钟）
3. 看到 "服务器已启动" 后，打开浏览器访问 **http://localhost:3000**
4. 输入账号 `admin`，密码 `admin123` 登录

## 功能说明

| 功能 | 说明 |
|------|------|
| 首页概览 | 查看学员总数、待审核申请等统计数据 |
| 学员管理 | 查看、搜索、添加、编辑、删除学员 |
| 批量导入 | 上传 Excel 文件批量导入学员（支持自定义模板）|
| 入校申请 | 审批学员的入校申请（通过/拒绝）|
| 账户管理 | 查看所有已生成的学员账户 |

## Excel 导入模板格式

表头需包含以下字段（系统会自动识别各种名称）：

| 字段 | 可识别的表头名称 |
|------|----------------|
| 姓名 | 姓名、名字、学员姓名、学生姓名 |
| 联系电话 | 联系电话、手机号、手机、电话、手机号码 |
| 班级名称 | 班级名称、班级、课程名称、课程 |
| 上课时间段 | 上课时间段、上课时间、时间、时间段 |
| 上课截止时间 | 上课截止时间、截止时间、截止日期、结束时间 |
| 上课地点 | 上课地点、地点、教室、上课教室 |

## 注意事项
- 启动前确保电脑能联网
- 如端口 3000 被占用，可修改 `server.js` 最后的 `PORT` 值
- Excel 文件必须是 .xlsx 或 .xls 格式
