# admin-server — 管理后台服务端

杭职大继续教育培训服务管理系统的 Web 管理端（Node + Express）。不直接读写数据库，全部登录与数据操作经云函数 `adminApi` 完成；接口前缀 `/api`，前端相对路径，本机与云上通用。

## 快速启动（3 步）

1. **装 Node.js**：https://nodejs.org/ 下载 LTS 版，安装一路下一步。
2. **配置密钥**：`copy config.example.json config.json`，填入以下字段（取值来源见根目录 `wx小程序云空间的配置信息/云空间配置说明.md`，值不入库）：
   - `env` 云环境 ID、`appId`、`appSecret`（微信公众平台 → 开发设置）
   - `adminApiSecret` 与云函数 `adminApi` 环境变量 `ADMIN_API_SECRET` **必须完全一致**，否则登录全部失败（fail-closed）
3. **启动**：`npm install` 后 `node server.js`（或双击 `启动管理后台.bat` / 运行 `start.ps1`），看到启动横幅后访问 `http://localhost:3000`。

上线常驻：`pm2 start server.js --name admin-api`；改配置后 `pm2 restart admin-api`。

## 统一鉴权模型（与小程序一致）

1. 服务端调云函数带 `secret`，云函数校验其与环境变量 `ADMIN_API_SECRET` 是否一致；未配置则全部失败。
2. 浏览器不保存密码，只保存云函数签发的 7 天随机 token（`sessions` 集合），改密后全部撤销。
3. 管理员密码在库里是 scrypt 加盐哈希（`scrypt$salt$hash`），登录时自动把旧明文数据重哈希。
4. 登录限速：同账号 10 分钟内失败 5 次 → 锁 10 分钟。
5. 普通管理员、被重置密码的账号首登**强制修改密码**（不可跳过）；超管不强制。默认种子账号首登同样强制改密一次——**部署后立即修改默认口令**（取值逻辑见 `server.js` 启动横幅与 `adminApi` 的 `initDefaultAdmin`）。
6. 仅超管可增删管理员、导入管理员；普通管理员只能查看分管班级的学员/申请/统计（分管班级为空则可查看全部）。

## 功能清单

仪表盘统计（按分管班级过滤）、学员管理（增删改查/重置密码/批量删除/Excel 导入导出）、入校申请审批、账户管理（学员账号同步）、班级管理、管理员账号（超管，含重置密码）、个人主页（修改本人姓名/账号/密码）、温馨提示（按班级）。

导出与模板下载走带 `Authorization` 的 blob 下载；表格中姓名、身份证等用户输入渲染时统一转义（XSS 防护）；身份证完整号码仅超管后台可见，小程序学生端显示时脱敏。

## Excel 导入模板

表头需包含以下字段（系统自动识别各种名称，字段可用别名）：

| 字段 | 可识别的表头名称 |
|------|----------------|
| 姓名 | 姓名、名字、学员姓名、学生姓名 |
| 联系电话 | 联系电话、手机号、手机、电话、手机号码 |
| 班级名称 | 班级名称、班级、课程名称、课程 |
| 上课时间段 | 上课时间段、上课时间、时间、时间段 |
| 上课截止时间 | 上课截止时间、截止时间、截止日期、结束时间 |
| 上课地点 | 上课地点、地点、教室、上课教室 |

文件必须是 `.xlsx` 或 `.xls`；上传用 `multer` 存 `uploads/`，临时文件用完即删。

## 测试与检查

```powershell
npm run check   # 全套静态守卫（详见根 README）
# e2e 前先启动本地服务；凭据经环境变量本地注入，不入库：
$env:ADMIN_PASS='<你的超管密码>'; npm run e2e
```

e2e 会在库中真实创建/删除临时夹具账号，**不要在生产库运行**。

## 目录结构

| 路径 | 说明 |
|------|------|
| `server.js` | Express 入口：`/api` 代理、鉴权、上传、导出、安全响应头 |
| `public/` | 前端单页（`index.html` + `admin.css` + `vendor/` 本地脚本） |
| `shared/` | 导入/课程日期单源（UMD），副本经 `scripts/sync-shared.js` 分发 |
| `scripts/` | 守卫与工具：`check-*.js`、`export-cloud.js`（云数据导出）、`sync-shared.js` |
| `test/` | e2e 三批次（权限矩阵/班级隔离/并发） |
| `config.json` | 本地密钥（`.gitignore` 排除，勿提交） |

## 常见问题

| 现象 | 处理 |
|------|------|
| 登录提示「云函数调用失败」 | 两处 `ADMIN_API_SECRET` 是否一致；云函数是否已「上传并部署」 |
| 部署后打开是旧页面 | 服务器 `pm2 restart admin-api` |
| 端口 3000 被占用 | 改 `server.js` 末尾 `PORT`，安全组同步放行 |
| 忘记管理员密码 | 超管在「管理员管理」点重置；库中无超管时用部署默认种子账号（仅 `admins` 集合为空时可用，首登强制改密） |

## 注意事项

- 启动前确保能联网（登录依赖云函数）。
- 首次使用前确认 `config.json` 四项密钥齐全，否则登录全挂。
